Peru Seismic Intelligence

Interactive earthquake monitoring for Peru, backed by an automated data pipeline.

This project combines historical records, annual report data, and live seismic updates from official IGP sources. The dashboard below is published in Tableau Public, while the underlying CSV and GeoJSON feeds are refreshed automatically in GitHub.

Refresh Logic

GitHub Actions runs the ingestion pipeline on a schedule, commits refreshed export files back to the repository, and keeps the dashboard data source current without requiring a local machine to stay on.

The dashboard itself is Tableau Public. This project site is the presentation layer that embeds it and documents the live data products behind it.
